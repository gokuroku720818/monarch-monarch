## V180: 명령 중 자동 일시정지

일반 병사 단일·다중 선택과 장군 명령을 내리는 동안 게임 시간과 적군 시뮬레이션을 잠시 정지합니다. 목적지/명령/후속 행동을 고르는 동안 정지가 유지되며 명령을 확정하거나 부대 선택을 완전히 취소하면 재개합니다. 실패한 명령이나 목적지 재선택은 정지를 유지해 명령을 다시 고를 수 있습니다. 사용자가 일시정지 버튼으로 직접 멈춘 경우 명령 종료 후에도 일시정지가 유지됩니다. 스테이지를 바꿨을 때 일시정지 버튼의 오래된 '재개' 표시도 초기화합니다.

기존 `commandPause` 변수를 호출 경로에서 모두 false로 설정하던 문제를 재현하고 수정했습니다. V179에서 재현 실패→V180에서 Chromium 양 판 23개 상태 검사 및 실제 캔버스 클릭 검사를 통과했습니다. Node 회귀 테스트, 맵 75개×100틱 브라우저 테스트, 원본 맵·음향·스프라이트 자산 검사를 통과했습니다. 자세한 근거와 한계는 [V180 비교 보고서](V180_ORIGINAL_COMPARISON_REPORT.md)에 기록했습니다. **원작 Windows EXE에서도 명령 입력 중 정지하는지는 직접 실행 비교하지 못했습니다.**

## 남은 원작 대조

Windows EXE와 HTML의 AI·경제·전투·승패를 동일한 입력으로 장시간 대조하는 검증은 아직 완료되지 않았습니다. V180은 검증된 입력 중 일시정지 동작을 개선한 단계이지 완전 복원판은 아닙니다.
