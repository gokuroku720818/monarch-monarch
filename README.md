## V174 변경점

휴대폰에서 한 병사 터치는 작동하지만 여러 병사를 드래그로 선택할 수 없었던 문제를 수정했습니다. 한 손가락 터치 동작을 기존 PC 마우스 선택 처리에 연결하여 원작 기반 부대 선택·명령 규칙을 중복 구현하거나 변경하지 않습니다. 터치 취소와 화면 밖 터치 종료도 정리했습니다. 이동·전투·AI·경제·맵·효과음 데이터는 변경하지 않았습니다.

## 이전 V173 변경점

원작 Windows WAV 파일명 대소문자 비구분 동작을 복원했습니다. `lm0200.wav`와 `LM0200.WAV`처럼 대소문자를 달리 호출해도 원본 효과음이 검색되도록 조정했습니다.

## 원작 데이터 및 자동 회귀 검사

`python3 tests/test_original_parity.py index.html`로 원본에서 확인한 고정 해시값을 이용해 75개 맵 격자·제목·장군 위치 및 WAV 159개의 데이터 보존 여부를 검사할 수 있습니다. `scripts/upgrade_v174.py`와 `.github/workflows/upgrade-v174.yml`은 정확한 V173 Git Blob에서만 V174를 만들고 데이터 보존 및 JavaScript 구문 검사를 통과한 뒤 배포합니다. 근거와 남은 미검증 항목은 `V174_ORIGINAL_COMPARISON_REPORT.md` 참조.

## 배경음악 및 검증 범위
