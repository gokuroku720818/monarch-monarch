## V177 장군 패배 UI 오류 수정

아군 장군을 선택해 왕 명령 메뉴를 연 상태에서 아군 병력과 생산기지가 모두 사라지면 장군이 패배합니다. V176에서는 엔진이 선택을 직접 해제한 뒤 명령 메뉴는 그대로 남아 있었습니다. V177에서는 실제로 선택한 장군이 제거되는 경우 기존 UI 정리 함수를 강제로 호출해 오래된 명령 메뉴를 닫습니다. 장군이 선택되지 않은 경우 다른 부대의 명령 메뉴에 영향을 주지 않습니다. 원작 패배 판정·부대/경제/전투 알고리즘은 변경하지 않았습니다.
