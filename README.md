## V178: 높은 지형의 다리 건설 오류 수정

맵 M_000의 수면 `(16,7,2)`에 높은 둑 `(15,7,5)`의 병력으로 다리 건설 명령을 내리면 V177 UI는 **다리 상판 z=3** 기준으로 명령을 수락했지만, 작업 호출부와 `workBridge()`는 **수면 z=2**를 검사하여 작업을 거부했습니다. V178에서는 물 위에 건설할 때만 두 작업 판정을 모두 상판 `z+1`로 일치시켰습니다. 원래 완성·손상된 다리의 판정, 비용, 기타 전투·경제 규칙은 변경하지 않았습니다.

수정 전 실패 테스트를 만들고, 수정 후 Node 회귀 테스트 및 Chromium 실제 실행에서 5틱 안에 다리가 완성되는 것을 확인했습니다. 원본 데이터 75개 맵·159개 WAV·이미지/음성 Base64 23개는 보존했습니다. 검증 범위와 미검증 항목은 [V178 비교 보고서](V178_ORIGINAL_COMPARISON_REPORT.md)에 명시했습니다.
