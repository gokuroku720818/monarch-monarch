# 모나크모나크 HTML 복원 프로젝트

원작 동작을 대조하며 개발 중인 비공식 HTML 복원판입니다. 원작과 완전히 동일하다고 검증된 버전은 아닙니다.

## V171 배포 상태

저장소 초기화 및 배포 안내를 먼저 등록했습니다. **게임 본편 `index.html`과 `monarch_v171_lite.html`은 아직 업로드되지 않았습니다.** 게임 실행 파일은 ChatGPT 대화에서 제공한 `monarch-monarch-v171-github-ready.zip`을 풀어 업로드해야 합니다.

업로드할 파일: `index.html`(전체판), `monarch_v171_lite.html`(배경음악 제외), `V171_ORIGINAL_COMPARISON_REPORT.md`(원작 비교 보고서).

## GitHub Pages

게임 파일 업로드가 끝난 뒤 Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save. 배포 완료 여부와 실제 주소는 Pages 설정에서 확인하세요.

## 유의

원작의 자산·음악에 관한 권리는 각 권리자에게 있습니다. 원작 공식 배포판이 아니며, 공개 배포 권한은 별도 확인이 필요합니다.
